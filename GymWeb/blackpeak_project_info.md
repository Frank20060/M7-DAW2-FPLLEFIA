BlackPeak Fitness - Proyecto Web
=================================

**Eslogan:** Activa la bestia

---

## 1. Información General

**Nombre del Proyecto:** BlackPeak Fitness
**Tema:** Gimnasio moderno
**Objetivo:** Crear una página web dinámica de un gimnasio ficticio usando PHP y MySQL con funcionalidades completas de CRUD, sistema de autenticación, panel de administración y secciones dinámicas.

## 3. Funcionalidades de la Web

- Inicio con hero y CTA
- Planes y tarifas
- Horario y clases
- Entrenadores
- Portfolio y testimonios
- Blog y noticias
- Comentarios y respuestas

---

## 4. Sistema de Sprints Simplificado

#### Sprint 1 — Preparación del Proyecto
**Objetivos:**
- Descargar template Agen Bootstrap
- Definir identidad de la empresa
- Adaptar el template a PHP
- Deploy inicial a Alwaysdata

**Resultado:** Web online y base de proyecto en PHP

#### Sprint 2 — Base de Datos
**Objetivos:**
- Diseñar esquema ER
- Crear tablas (usuarios, noticias, portfolio, testimonios, comentarios, FAQs)
- Insertar datos de prueba
- Documentar consultas SQL básicas

**Resultado:** Base de datos funcional

#### Sprint 3 — Contenido Dinámico
**Objetivos:**
- Dinamizar portfolio, testimonios, noticias del blog
- Crear página de detalle de noticias con comentarios

**Resultado:** Contenido cargado desde MySQL

#### Sprint 4 — Usuarios y Autenticación
**Objetivos:**
- Registro y login
- Gestión de roles (user/admin)
- Hashing de contraseñas

**Resultado:** Usuarios funcionando con seguridad

#### Sprint 5 — Panel de Administración
**Objetivos:**
- Panel accesible solo para admin
- CRUD para todas las entidades

**Resultado:** Administrador controla todo el contenido

#### Sprint 6 — Extras
**Objetivos:**
- Página de contacto con envío de correo
- Integrar mapa
- Dinamizar FAQs

**Resultado:** Funcionalidades extra completadas
